# لیست وضعیت پروژه (تسک‌ها)

در این بخش، مستندات تمامی وظایف انجام شده و لیست مسیر جدید توسعه برای مهاجرت کامل به هاست سی‌پنل شخصی شما به صورت گام به گام مدیریت می‌شود.

---

## ✅ کارهای انجام شده 

- [x] رفع خطای مربوط به نبودن `db` در صفحات `Reader.tsx` و `Profile.tsx` (اضافه کردن ایمپورت صحیح فایربیس)
- [x] رفع خطای `Missing or insufficient permissions` برای آپدیت بازدیدهای (views) چپترها و کمیک‌ها در دیتابیس
- [x] رفع خطای `Encountered two children with the same key` در کامپوننت `SortableImageList` هنگام آپلود تصاویر پنل ادمین
- [x] اصلاح `serverTimestamp` در آپدیت پروفایل کاربر و تاریخچه خواندن کمیک‌ها
- [x] نصب پکیج‌های پیش‌نیاز سرور برای MySQL و Real-time (Socket.io)
- [x] هماهنگ‌سازی و آماده‌سازی ساختار چندلایه‌ای سرور Full-stack (Express & tsx)
- [x] **توسعه بخش لوکال دیتابیس هوشمند (JSON/File-based fallback)** جهت کارکرد زنده و بدون وقفه در محیط AI Studio دیتابیس به صورت کاملاً هوشمند طراحی شده تا بدون کانفیگ اولیه به راحتی کار کند.
- [x] **توسعه ماژول اتصال به دیتابیس MySQL هاست سی‌پنل** با پشتیبانی از Pool اتصالات با کیفیت بالا و تراکنش‌ها.
- [x] **راه‌اندازی روت‌های جامع API بک‌اند** برای کمیک‌ها، چپترها، نظرها، کاربران، لایک/دیس لایک، بوک‌مارک، تنظیمات سایت و تاریخچه بازدید بدون وابستگی به فایربیس.
- [x] **اتصال کامل تمام کدهای فرانت‌اند (شامل هدرها، لیدربورد، صفحه خواننده، کامنت‌ها و پروفایل)** از بستر فایربیس قدیمی به وب‌سرویس apiClient پر سرعت جدید با سوکت آنلاین (Socket.io).
- [x] **ارائه راهنمای گام به گام ساده و فارسی فوق‌العاده دقیق** به نام `CPANEL_GUIDE.md` برای ساخت دیتابیس، فعالسازی Remote MySQL و ثبت مشخصات به همراه تمام کدهای ایمپورت دستی جداول در phpMyAdmin هاست شما.
